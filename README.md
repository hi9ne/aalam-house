# ААЛАМ House

Лендинг агентства недвижимости в Бишкеке. Next.js (App Router), TypeScript, Tailwind CSS.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:3000.

Перед коммитом:

```bash
npm run lint
npm run build
```

## Заявки в Telegram

Форма в блоке контактов отправляет заявку ботом в Telegram-чат. Нужны две переменные окружения:

| Переменная | Что это |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather |
| `TELEGRAM_CHAT_ID` | ID чата или группы, куда бот пишет заявки |

Локально: скопировать `.env.example` в `.env.local` и заполнить. На Vercel: добавить обе переменные в настройках проекта. Без них форма показывает посетителю ошибку и просит позвонить.

## Где менять содержимое

| Что | Файл |
| --- | --- |
| Телефон, WhatsApp, Telegram, Instagram, адрес, часы работы, меню | `src/data/site.ts` |
| Объекты каталога | `src/data/listings.ts` |
| Тексты блоков, цифры, услуги, отзывы, команда, FAQ, ставка калькулятора | `src/data/content.ts` |
| Цвета и скругления | `src/app/globals.css` |
| Картинки | `public/img` |
| Политика обработки персональных данных | `src/app/privacy/page.tsx` |

Кнопки Telegram и Instagram появляются в блоке контактов, когда в `site.ts` заполнены ссылки.

## Что на сайте временное

- Объекты, цены, цифры, отзывы и команда — заглушки из макета.
- Ссылки на Telegram и Instagram и адрес офиса в `site.ts` выдуманы.
- Фото объектов, районов, офиса и первого экрана сгенерированы ИИ. Портреты команды и клиентов — иллюстрации.
- Политика обработки персональных данных — черновик, не согласованный с юристом.
- Сайт закрыт от поисковиков (`indexable: false` в `site.ts`), пока на нём заглушки. Перед запуском поставить `true`.

## Избранное

Сердечко на карточке сохраняет объект в браузере посетителя (`localStorage`). Чип «Избранное» в каталоге показывает сохранённые объекты, а при отправке заявки их список уходит менеджеру вместе с контактами.
